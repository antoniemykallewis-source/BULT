# BULT × Harris Rudman — The Work. The Life.

This folder is a complete static pitch site. It has no build step and no dependencies.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and the complete `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will display the live URL when deployment finishes.

Keep the `assets` folder beside `index.html`; the site uses relative paths so it works on any GitHub Pages repository URL.

- Animated performance figures
